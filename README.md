# Hire4Play Landing Page

GitHub Pages package for the supplied Hire4Play landing page.

## Publish
1. Extract this ZIP on your computer.
2. Open your GitHub repository.
3. Choose **Add file → Upload files**.
4. Upload `index.html`, `.nojekyll`, and `README.md` to the repository root (not inside a subfolder).
5. Commit the changes to the `main` branch.
6. Open **Settings → Pages**.
7. Select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
8. Wait for the deployment and open the URL displayed in the Pages section.

## Notes
- The supplied page includes its own HTML, CSS, JavaScript, and embedded image data; no separate `app.jsx` or `styles.css` is required for this landing-page file.
- Google Fonts are loaded from Google Fonts, so that typography needs an internet connection. The page itself has no external JavaScript file references.
- GitHub Pages hosts static files only. Any feature requiring a server, database, or secure authentication needs a separate backend.
